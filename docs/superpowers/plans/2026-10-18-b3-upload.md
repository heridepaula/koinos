# Upload dos extratos da B3 pela tela: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O usuário importa os extratos de Negociação e de Movimentação da B3 (e, se quiser, a planilha) pela tela `/transacoes/importar`, sem rodar script. A prévia mostra o que muda e as pendências; a confirmação grava.

**Architecture:**
- **Reuso do núcleo:** os leitores, o reconhecimento e o `planB3Import` já existem (commit 182b20b) e são usados como estão.
- **Servidor:** um serviço novo (`server/b3-import.ts`) lê os arquivos do formulário em memória, valida e monta o plano. A prévia vai ao navegador sem ids internos. A confirmação recalcula tudo dentro de uma trava por carteira e grava numa transação do Mongo.
- **Tela:** um assistente de 3 passos (arquivos, prévia com pendências, importar), em componentes cliente da feature `transactions`.

**Tech Stack:** Next.js 16 (Server Actions, `experimental.serverActions.bodySizeLimit`), next-safe-action 8 (`useAction`), Zod 4, `read-excel-file/node` (aceita `Blob`), Mongoose 9, Redis (trava).

**Spec:** `docs/superpowers/specs/2026-10-18-importacao-b3-design.md` (§7, §8, §10, §11 e §13).

**Ajustes ao spec, decididos aqui:**
- **Limites de arquivo:**
  - até 2 MB por arquivo, e não 5 MB: a Vercel limita o corpo da requisição a 4,5 MB, e os extratos reais somam 215 KB;
  - `bodySizeLimit` de 4 MB.
- **Um só seletor de arquivos** (com arrastar e soltar) em vez de três campos: o reconhecimento é pelo cabeçalho, no servidor, e a prévia mostra o que foi reconhecido.
- **"Reenvio = zero mudanças":** o plano sempre troca os lançamentos B3 do período. O serviço compara o que sai com o que entra e conta novos, removidos e iguais. Sem mudança real, a confirmação não grava nada.
- **Divergências na conferência pelos rendimentos:** com divergência sem explicação, a importação pede um "revisei" explícito, como o `--aceitar-divergencias` do script.

**Sem testes automatizados** (decisão do usuário). Cada tarefa se verifica com `npm run typecheck`, `npm run lint` e `npm run build`. A Tarefa 4 faz o upload real na prévia isolada.

```ts
const fiiCode = z.string().regex(/^[A-Z0-9]{4}11$/);

/** Respostas às pendências da importação da B3 (spec §7). Os ids são recalculados no servidor. */
export const b3AnswersSchema = z.object({
  prices: z.record(z.string().regex(/^(sub|prev):[A-Z0-9]{4}11\b/), z.number().positive()).default({}),
  conversions: z
    .record(z.string().regex(/^conv:[A-Z0-9]{4}11:/), z.union([fiiCode, z.literal("NONE")]))
    .default({}),
  exclude: z.array(fiiCode).max(200).default([]),
});

/** Formulário da importação: os arquivos, as respostas (JSON) e o "revisei as divergências". */
export const b3ImportFormSchema = z.instanceof(FormData).transform((form, ctx) => {
  const files = form
    .getAll("files")
    .filter((value): value is File => value instanceof File && value.size > 0);
  const raw = form.get("answers");
  let answers: unknown = {};
  if (typeof raw === "string" && raw) {
    try {
      answers = JSON.parse(raw);
    } catch {
      ctx.addIssue({ code: "custom", message: "Respostas inválidas." });
      return z.NEVER;
    }
  }
  const parsed = b3AnswersSchema.safeParse(answers);
  if (!parsed.success) {
    ctx.addIssue({ code: "custom", message: "Respostas inválidas." });
    return z.NEVER;
  }
  return { files, answers: parsed.data, acceptDivergences: form.get("acceptDivergences") === "true" };
});

export type B3ImportRequest = z.output<typeof b3ImportFormSchema>;
```

- [ ] **Step 2: Serviço `src/features/transactions/server/b3-import.ts`**

```ts
import "server-only";
import readXlsxFile from "read-excel-file/node";
import { ActionError, type Tenant } from "@/features/auth/server";
import { readCatalogTypes } from "@/features/market-data/server";
import { withLock } from "@/shared/db/lock";
import { detectB3File } from "../import/b3/detect";
import { B3ImportError, planB3Import } from "../import/b3/plan";
import { readMovimentacao } from "../import/b3/read-movimentacao";
import { readNegociacao } from "../import/b3/read-negociacao";
import type { B3FileKind, B3ImportPlan, PlannedTransaction } from "../import/b3/types";
import { parsePlanilha, type SheetInput } from "../import/parse-planilha";
import type { B3ImportRequest } from "../schemas";
import { applyTransactionChanges, listTransactions, type TransactionRecord } from "./transaction-repo";

// Importação dos extratos da B3 pela tela (spec importacao-b3, §8, §10 e §11). Os arquivos são
// lidos em memória e descartados; a cada chamada, tudo é recalculado no servidor.

const MAX_FILES = 3;
const MAX_FILE_BYTES = 2 * 1024 * 1024;
const MAX_ROWS = 50_000;
const LOCK_TTL_MS = 60_000;
const ZIP_SIGNATURE = [0x50, 0x4b, 0x03, 0x04];
const FILE_LABELS: Record<B3FileKind, string> = {
  NEGOCIACAO: "Negociação",
  MOVIMENTACAO: "Movimentação",
  PLANILHA: "planilha",
};

export type B3ImportChanges = { added: number; removed: number; unchanged: number };

/** Prévia para o navegador: os lançamentos viram contagens, sem ids internos. */
export type B3ImportPreview = Omit<B3ImportPlan, "inserts" | "removeIds"> & {
  files: B3FileKind[];
  changes: B3ImportChanges;
  /** Algum FII ainda depende de resposta. */
  blocked: boolean;
};

async function readSheets(file: File): Promise<SheetInput[]> {
  if (file.size > MAX_FILE_BYTES) throw new ActionError(`${file.name} passa de 2 MB.`);
  const head = new Uint8Array(await file.slice(0, ZIP_SIGNATURE.length).arrayBuffer());
  if (!ZIP_SIGNATURE.every((byte, index) => head[index] === byte)) {
    throw new ActionError(`${file.name} não é uma planilha .xlsx.`);
  }
  return (await readXlsxFile(file)) as unknown as SheetInput[];
}

async function recognize(files: readonly File[]) {
  if (files.length === 0 || files.length > MAX_FILES) {
    throw new ActionError(
      "Envie os extratos de Negociação e de Movimentação e, se quiser, a sua planilha.",
    );
  }
  const found = new Map<B3FileKind, SheetInput[]>();
  let rows = 0;
  for (const file of files) {
    const sheets = await readSheets(file);
    rows += sheets.reduce((sum, sheet) => sum + sheet.data.length, 0);
    if (rows > MAX_ROWS) throw new ActionError("Os arquivos passam de 50.000 linhas.");
    const kind = detectB3File(sheets);
    if (!kind) {
      throw new ActionError(
        `Não reconheci ${file.name}. Envie os extratos baixados da Área do Investidor da B3.`,
      );
    }
    if (found.has(kind)) throw new ActionError(`Chegaram dois arquivos de ${FILE_LABELS[kind]}.`);
    found.set(kind, sheets);
  }
  const negociacao = found.get("NEGOCIACAO");
  const movimentacao = found.get("MOVIMENTACAO");
  if (!negociacao || !movimentacao) {
    throw new ActionError(`Falta o extrato de ${negociacao ? "Movimentação" : "Negociação"}.`);
  }
  return { negociacao, movimentacao, planilha: found.get("PLANILHA") ?? null, kinds: [...found.keys()] };
}

async function buildPlan(tenant: Tenant, request: B3ImportRequest) {
  const files = await recognize(request.files);
  const [existing, assetTypes] = await Promise.all([
    listTransactions(tenant.portfolioId),
    readCatalogTypes(),
  ]);
  if (assetTypes.size === 0) {
    throw new ActionError("O catálogo de tickers ainda não foi carregado. Tente de novo em alguns minutos.");
  }
  try {
    const plan = planB3Import({
      negociacao: readNegociacao(files.negociacao),
      movimentacao: readMovimentacao(files.movimentacao),
      planilha: files.planilha ? parsePlanilha(files.planilha) : null,
      existing,
      assetTypes,
      answers: request.answers,
    });
    return { plan, existing, kinds: files.kinds };
  } catch (error) {
    // Erros de conteúdo dos arquivos já vêm com mensagem para o usuário.
    if (error instanceof B3ImportError) throw new ActionError(error.message);
    throw error;
  }
}

type Comparable = Pick<
  PlannedTransaction,
  "ticker" | "type" | "quantity" | "unitPrice" | "fees" | "date" | "kind" | "priceSource" | "relatedTicker" | "notes"
>;
const signature = (entry: Comparable) =>
  [
    entry.ticker,
    entry.type,
    entry.quantity,
    entry.unitPrice,
    entry.fees,
    entry.date.toISOString(),
    entry.kind,
    entry.priceSource ?? "",
    entry.relatedTicker ?? "",
    entry.notes ?? "",
  ].join("|");

/** Quantos lançamentos realmente mudam: o plano troca tudo, mas um reenvio igual não muda nada. */
function compare(plan: B3ImportPlan, existing: readonly TransactionRecord[]): B3ImportChanges {
  const removing = new Set(plan.removeIds);
  const pool = new Map<string, number>();
  for (const entry of existing) {
    if (!removing.has(entry.id) || entry.source !== "B3") continue;
    const key = signature(entry);
    pool.set(key, (pool.get(key) ?? 0) + 1);
  }
  let unchanged = 0;
  for (const insert of plan.inserts) {
    const key = signature(insert);
    const left = pool.get(key) ?? 0;
    if (left > 0) {
      pool.set(key, left - 1);
      unchanged++;
    }
  }
  return {
    added: plan.inserts.length - unchanged,
    removed: plan.removeIds.length - unchanged,
    unchanged,
  };
}

const isBlocked = (plan: B3ImportPlan) => plan.tickers.some((item) => item.status === "PENDENTE");

export async function previewB3Import(
  tenant: Tenant,
  request: B3ImportRequest,
): Promise<B3ImportPreview> {
  const { plan, existing, kinds } = await buildPlan(tenant, request);
  const { inserts: _inserts, removeIds: _removeIds, ...rest } = plan;
  return { ...rest, files: kinds, changes: compare(plan, existing), blocked: isBlocked(plan) };
}

export async function confirmB3Import(
  tenant: Tenant,
  request: B3ImportRequest,
): Promise<{ removed: number; inserted: number }> {
  const result = await withLock(`import:${tenant.portfolioId}`, LOCK_TTL_MS, async () => {
    const { plan, existing } = await buildPlan(tenant, request);
    if (isBlocked(plan)) {
      throw new ActionError("A prévia mudou e há pendências sem resposta. Gere a prévia de novo.");
    }
    if (plan.check.unexplained.length > 0 && !request.acceptDivergences) {
      throw new ActionError(
        "A conferência pelos rendimentos tem divergências. Confirme que revisou para importar mesmo assim.",
      );
    }
    const changes = compare(plan, existing);
    if (changes.added === 0 && changes.removed === 0) return { removed: 0, inserted: 0 };
    return applyTransactionChanges(tenant.portfolioId, {
      removeIds: plan.removeIds,
      inserts: plan.inserts,
      source: "B3",
    });
  });
  if (!result) {
    throw new ActionError("Outra importação desta carteira está em andamento. Tente de novo em instantes.");
  }
  return result;
}

import { parseNumberInput } from "@/shared/lib/parse-number";
import type { B3ImportPreview } from "../../server/b3-import";

/** O que o usuário respondeu na tela (os preços como texto, do jeito que foram digitados). */
export type AnswersDraft = {
  prices: Record<string, string>;
  conversions: Record<string, string>;
  exclude: string[];
  acceptDivergences: boolean;
};

export const emptyDraft = (): AnswersDraft => ({
  prices: {},
  conversions: {},
  exclude: [],
  acceptDivergences: false,
});

/**
 * Respostas para o servidor. Só vão os preços digitados (um preço já guardado continua com a
 * origem dele, "estimado" inclusive); a conversão sem escolha vai com a sugestão marcada na tela.
 */
export function toAnswers(draft: AnswersDraft, preview: B3ImportPreview | null) {
  const prices: Record<string, number> = {};
  for (const [id, text] of Object.entries(draft.prices)) {
    const value = parseNumberInput(text);
    if (Number.isFinite(value) && value > 0) prices[id] = value;
  }
  const conversions: Record<string, string> = {};
  for (const item of preview?.pending ?? []) {
    if (item.type !== "CONVERSAO") continue;
    const chosen = draft.conversions[item.id] ?? item.source ?? item.suggestion;
    if (chosen) conversions[item.id] = chosen;
  }
  return { prices, conversions, exclude: draft.exclude };
}
```

export function FilePicker({ files, onChange }: { files: File[]; onChange: (files: File[]) => void }) {

"use client";

import { useAction } from "next-safe-action/hooks";
import { useRouter } from "next/navigation";
import { useState } from "react";
import { toast } from "sonner";
import { actionErrorMessage } from "@/shared/lib/action-error";
import { Button } from "@/shared/ui/button";
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/shared/ui/card";
import { Spinner } from "@/shared/ui/spinner";
import { confirmB3ImportAction, previewB3ImportAction } from "../../actions";
import type { B3ImportPreview } from "../../server/b3-import";
import { emptyDraft, toAnswers, type AnswersDraft } from "./answers";
import { FilePicker } from "./file-picker";
import { PendingList } from "./pending-list";
import { DividendCheck, IgnoredAndWarnings, PreviewSummary, TickerTable } from "./preview-sections";

/** Importação dos extratos da B3: arquivos → prévia (com pendências) → importar. */
export function B3ImportWizard() {
  const router = useRouter();
  const [files, setFiles] = useState<File[]>([]);
  const [draft, setDraft] = useState<AnswersDraft>(emptyDraft);
  const [preview, setPreview] = useState<B3ImportPreview | null>(null);
  const [dirty, setDirty] = useState(false);

  const toForm = () => {
    const form = new FormData();
    for (const file of files) form.append("files", file);
    form.append("answers", JSON.stringify(toAnswers(draft, preview)));
    form.append("acceptDivergences", String(draft.acceptDivergences));
    return form;
  };
  const previewAction = useAction(previewB3ImportAction, {
    onSuccess: ({ data }) => {
      if (!data) return;
      setPreview(data);
      setDirty(false);
    },
    onError: ({ error }) => toast.error(actionErrorMessage(error)),
  });
  const confirmAction = useAction(confirmB3ImportAction, {
    onSuccess: ({ data }) => {
      toast.success(
        data && data.inserted + data.removed > 0
          ? `Importado: ${data.inserted} lançamentos da B3 (${data.removed} substituídos).`
          : "Nada mudou: a carteira já está igual aos extratos.",
      );
      router.push("/transacoes");
    },
    onError: ({ error }) => toast.error(actionErrorMessage(error)),
  });

  const change = (next: AnswersDraft) => {
    setDraft(next);
    setDirty(true);
  };
  const busy = previewAction.isPending || confirmAction.isPending;
  const divergent = (preview?.check.unexplained.length ?? 0) > 0;
  const canImport =
    preview !== null && !preview.blocked && !dirty && (!divergent || draft.acceptDivergences);

  return (
    <div className="grid gap-6">
      <Card>
        <CardHeader>
          <CardTitle>Arquivos</CardTitle>
          <CardDescription>
            Na Área do Investidor da B3, em Extratos, baixe Negociação e Movimentação em Excel, do
            período inteiro que você quer importar.
          </CardDescription>
        </CardHeader>
        <CardContent className="grid gap-4">
          <FilePicker
            files={files}
            onChange={(next) => {
              setFiles(next);
              setPreview(null);
              setDraft(emptyDraft());
            }}
          />
          <div className="flex flex-wrap gap-2">
            <Button
              type="button"
              variant={preview ? "outline" : "default"}
              disabled={files.length < 2 || busy}
              onClick={() => previewAction.execute(toForm())}
            >
              {previewAction.isPending ? <Spinner /> : null}
              {preview ? "Atualizar prévia" : "Gerar prévia"}
            </Button>
            {preview ? (
              <Button type="button" disabled={!canImport || busy} onClick={() => confirmAction.execute(toForm())}>
                {confirmAction.isPending ? <Spinner /> : null}
                Importar
              </Button>
            ) : null}
          </div>
          {preview && dirty ? (
            <p className="text-sm text-muted-foreground">Você mudou respostas: atualize a prévia para conferir antes de importar.</p>
          ) : null}
          {preview?.blocked && !dirty ? (
            <p className="text-sm text-muted-foreground">Responda as pendências (ou deixe o FII de fora) para liberar a importação.</p>
          ) : null}
        </CardContent>
      </Card>

      {preview ? (
        <>
          <PreviewSummary preview={preview} />
          {preview.pending.length > 0 ? (
            <Card>
              <CardHeader>
                <CardTitle>Pendências</CardTitle>
                <CardDescription>O que a B3 não informa e só você sabe.</CardDescription>
              </CardHeader>
              <CardContent>
                <PendingList preview={preview} draft={draft} onChange={change} />
              </CardContent>
            </Card>
          ) : null}
          <DividendCheck
            preview={preview}
            accepted={draft.acceptDivergences}
            onAccept={(value) => setDraft({ ...draft, acceptDivergences: value })}
          />
          <TickerTable preview={preview} />
          <IgnoredAndWarnings preview={preview} />
        </>
      ) : null}
    </div>
  );
}
